# 정상 서비스 기준선

- 환경: 로컬 Python 3.13
- 의존 서비스: 결정적 모의 LLM
- 입력: 무선 이어폰, 129000원, 기존 제품 고장
- 시간 기준: UTC 정책을 따르는 사건 로그 기준

## 정상 결과 기준

- 코칭 상태: `ok`
- 숙고 질문: 3개 이상
- 소비 점검 결과: 비어 있지 않은 문자열
- 외부 네트워크 호출: 없음
- 정상 입력 오류: 0건
